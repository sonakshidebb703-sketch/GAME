**GAME 1- SIGNAL & SWAT**:-

**Description**: 
Signal & Swat : This game presents rapidly appearing targets on screen, requiring players to quickly tap designated "go" items (such as green circles) while
ignoring "no-go" visual distractions like red circles or green squares. Based on clinical assessments like the Go/No-Go Task and Continuous Performance Test
(CPT), it evaluates sustained attention, processing speed, and impulse control by tracking reaction times, missed targets, and false alarms.
